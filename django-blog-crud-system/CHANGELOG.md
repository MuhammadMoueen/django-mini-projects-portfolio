# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2026-02-23

### Added
- User profile picture support with ImageField
- Profile dropdown menu in navbar with user avatar
- Bootstrap Icons integration for better UI
- Back button on post detail page
- Media file handling configuration
- Default profile picture placeholder
- Profile dropdown with Home, Dashboard, Edit Profile, and Logout options

### Changed
- Redesigned navbar to use profile dropdown instead of individual links
- Simplified dashboard by removing action links from post cards
- Moved back button to top left on post detail page
- Updated authentication pages with password visibility toggle

### Improved
- Better user experience with profile-centric navigation
- Cleaner dashboard interface
- Enhanced visual design with profile avatars

## [1.0.0] - 2026-02-22

### Initial Release
- Full CRUD functionality for blog posts
- User authentication system
- Responsive design with Bootstrap 5
- Dashboard with statistics
- Search and filter functionality
- Author profile pages
