# Features Documentation

## Profile Management

### User Avatars
- Each user can have a profile picture
- Default avatar shows first letter of username
- Profile pictures are displayed in navbar dropdown
- Supports common image formats (JPG, PNG, GIF)

### Profile Dropdown Menu
The profile dropdown provides quick access to:
- **Home**: Return to main blog feed
- **Dashboard**: View your posts and statistics
- **Edit Profile**: Manage your profile settings
- **Logout**: Securely logout from the system

## Navigation

### Navbar Design
- Clean, minimal design with profile-centric approach
- Profile picture displayed with username
- Dropdown menu for all navigation options
- Responsive design for mobile devices

### Post Detail Page
- Back button positioned at top left for easy navigation
- Breadcrumb trail showing: Home > Author > Post
- Clean reading experience

## Dashboard

### Simplified Interface
- Posts displayed as cards
- No action buttons on cards for cleaner look
- Post management available through post detail page
- Statistics cards showing:
  - Total posts count
  - Posts this week
  - Recent activity

## Authentication

### Password Visibility Toggle
- Eye icon on password fields
- Click to show/hide password
- Available on both login and register pages
- Smooth icon transition animation
